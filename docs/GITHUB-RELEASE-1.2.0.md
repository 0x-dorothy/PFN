# PFN 1.2.0 — первый релиз

Локальный трекер личных финансов: денежный поток, капитал, бюджеты, цели,
регулярные платежи и активы. Всё считается на вашем компьютере, данные лежат в
одном файле и никуда не отправляются.

Один исполняемый файл вместо набора сервисов: SQLite вместо Postgres,
встроенная раздача интерфейса вместо nginx, установщик вместо инструкции по
запуску.

## Скачать

| Файл | Кому |
| --- | --- |
| **`PFN-1.2.0-Setup.exe`** | Windows 10/11 — обычная установка, ярлык в «Пуск» |
| `PFN-1.2.0-win64.zip` | Windows, если не хочется ничего устанавливать: распаковать и запустить `PFN.exe` |
| `SHA256SUMS.txt` | контрольные суммы для проверки скачанного |

Python, Node.js, Docker и Postgres **не нужны** — всё внутри.

## Установка

1. Запустить `PFN-1.2.0-Setup.exe`, нажимать «Далее».
2. Запустить **PFN** из меню «Пуск» или с рабочего стола.

Права администратора не требуются: программа ставится в профиль пользователя.

SmartScreen покажет «Windows защитила ваш компьютер» — сборка не подписана
сертификатом. «Подробнее» → «Выполнить в любом случае».

## Куда пишутся данные

`%APPDATA%\PFN\pfn.db` — один файл SQLite. Удаление программы его не трогает:
переустановка и обновления историю не теряют.

Резервная копия: **Настройки → Бэкап → Экспортировать** (JSON со всеми данными).
Он же — способ перенести всё на другой компьютер.

## Что в этом релизе

**Возможности приложения:**

- счета, доходы, расходы, переводы; категории с подкатегориями, теги, поиск;
- разделение одной покупки на несколько категорий;
- импорт CSV из Т-Банка, monobank и ПриватБанка;
- чистый капитал: график и разбивка по классам активов, риску и роли капитала;
- криптопортфель с историей покупок, средней ценой и P/L;
- бюджеты по категориям, цели с взносами, регулярные платежи;
- отчёты по категориям за период и правила-подсказки;
- калькулятор доходности с графиком сложного процента;
- оповещения: отрицательный поток, падение капитала, перерасход, риск,
  простаивающие деньги.

**Что сделано:**

- SQLite вместо Postgres, один процесс вместо трёх контейнеров;
- FastAPI сам отдаёт собранный интерфейс — nginx не нужен;
- установщик Windows и портативная сборка; своё окно приложения;
- акцентные цвета: шесть пресетов в дополнение к светлой/тёмной/системной теме;
- ребрендинг: название, иконка, ключи настроек и формат бэкапа вынесены в конфигурацию;
- исправлено восстановление бэкапа на SQLite (вызов `pg_get_serial_sequence`);
- убраны авторские материалы: маркетинговый README, `CLAUDE.md`, CI апстрима,
  Playwright-тесты, конфигурация TLS.

## Проверка файлов

```powershell
certutil -hashfile PFN-1.2.0-Setup.exe SHA256
```

Сравнить с соответствующей строкой в `SHA256SUMS.txt`. На macOS/Linux:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

## Известные ограничения

- **Пароля нет.** Приложение рассчитано на один компьютер и одного пользователя;
  не выставляйте его в интернет.
- **Криптовалюта** требует бесплатный ключ CoinGecko (`PFN_COINGECKO_API_KEY`);
  без него вкладка показывает ошибку, остальное работает офлайн.
- **macOS и Android** в этом релизе не поставляются: `.app`/`.dmg` собираются
  только на Mac, APK требует Android SDK. Код к этому подготовлен.
