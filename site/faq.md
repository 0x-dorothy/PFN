# Вопросы и ответы

## Это безопасно? Где мои данные?

База — файл на вашем диске. Приложение не отправляет данные наружу и не
требует аккаунта. Единственное исключение — запрос цен криптовалют к CoinGecko,
и только при наличии ключа.

## Есть ли пароль?

В самом приложении — нет. Оно рассчитано на один компьютер и одного
пользователя и по умолчанию слушает только `127.0.0.1`, то есть из сети
недоступно.

Если нужен доступ с телефона по домашней сети (`PFN.exe --host 0.0.0.0`),
помните: пароля там не появится. Ставьте приложение за reverse-proxy с Basic
Auth, если сеть не вызывает доверия.

## Почему не мобильное приложение?

Потому что честный офлайн-клиент для телефона — это отдельная реализация всего
слоя данных (агрегаты, отчёты, капитал), а не «обёртка». Пока телефон
открывает то же приложение по сети; PWA-оболочка и плагин для Obsidian — в
планах и в работе.

## Что с обновлениями?

Установщик ставится поверх: данные в `%APPDATA%` не затрагиваются. Перед
обновлением полезно сделать экспорт бэкапа — просто на всякий случай.

## Нужен ли интернет?

Для работы — нет. Для установки — да, если ставите из исходников (скачать
зависимости). Установщик и портативная сборка интернета не требуют.

## Антивирус ругается. Это нормально?

Для неподписанных сборок — да. Windows SmartScreen показывает предупреждение
для любого `.exe` без сертификата. Проверить подлинность файла можно по
`SHA256SUMS.txt` из релиза.
