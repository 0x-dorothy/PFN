# Лицензия

PFN распространяется по **PolyForm Noncommercial License 1.0.0**.

## Что можно

- Читать и изучать код.
- Запускать для себя, без ограничений по времени.
- Изменять под свои задачи.
- Передавать копию другим — для личных и учебных целей.

## Что нельзя

- Продавать программу или её изменённую версию.
- Размещать её как платный сервис для других людей.
- Строить на её основе коммерческий продукт.

Это **не** OSI-лицензия: код открыт для чтения, запуска и правок, но не для
коммерческого использования.

## Где полный текст

Файл `LICENSE` в [репозитории](https://github.com/0x-dorothy/PFN/blob/main/LICENSE).
Он же лежит рядом с программой после установки — по условиям лицензии текст
должен передаваться вместе с каждой копией.

## Данные

Данные принадлежат только вам: они лежат в файле на вашем компьютере, и
приложение не отправляет их наружу.
