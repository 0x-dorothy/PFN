# Установка

Нужен один файл. Ни Python, ни Node.js, ни Docker, ни Postgres — всё внутри.

## Windows

1. Скачайте `PFN-1.2.0-Setup.exe` со страницы
   [Releases](https://github.com/0x-dorothy/PFN/releases).
2. Двойной клик → «Далее» → «Установить».
3. Запустите **PFN** из меню «Пуск» или с рабочего стола.

Права администратора не нужны: программа ставится в профиль пользователя
(`%LOCALAPPDATA%\Programs\PFN`), там же лежит деинсталлятор.

{% hint style="warning" %}
**SmartScreen может сказать «Windows защитила ваш компьютер».** Сборка не
подписана сертификатом — он стоит денег и для учебного проекта не нужен.
Нажмите «Подробнее» → «Выполнить в любом случае».
{% endhint %}

## Без установки

`PFN-1.2.0-win64.zip` — та же программа в папке. Распакуйте куда угодно и
запустите `PFN.exe`. Удобно, если нельзя ставить программы или нужен «свой»
экземпляр на флешке.

## Первый запуск

Окно приложения открывается само. Внутри уже есть счёт по умолчанию, набор
категорий и настройки — можно сразу добавлять операции.

Если окно не появилось, разверните минимизированное окно `PFN` в панели задач:
там печатается причина. Подробный лог — `launcher.log` в каталоге данных
(см. [Данные и бэкап](data.md)).

## Остановить и удалить

- **Остановить:** ярлык «Остановить PFN» в меню «Пуск» или `PFN.exe --stop`.
- **Удалить:** «Параметры → Приложения → PFN» или `unins000.exe` в папке
  программы. База данных при удалении **не** стирается.

## Запуск из исходников

Для разработки — нужен Python 3.10+:

```bash
# Windows
start.bat

# macOS / Linux
./start.sh
```

Скрипт создаст окружение, поставит зависимости и откроет приложение.

## macOS и Android

Пока не поставляются. Код к сборке готов (`.app` собирается только на Mac,
APK требует Android SDK), но готовых файлов нет — не обещаем того, что не
проверено.
