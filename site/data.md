# Данные и бэкап

## Где лежит база

Один файл SQLite:

| ОС | Путь |
| --- | --- |
| Windows | `%APPDATA%\PFN\pfn.db` |
| macOS | `~/Library/Application Support/PFN/pfn.db` |
| Linux | `~/.local/share/PFN/pfn.db` |

Каталог можно перенести переменной `PFN_DATA_DIR` или флагом
`PFN.exe --data-dir D:\finance`. Программу при этом можно переустанавливать
как угодно — база лежит отдельно и удалением приложения не затрагивается.

## Бэкап

**Настройки → Бэкап → Экспортировать** — один JSON со всеми данными: счета,
категории, теги, транзакции, активы и оценки, бюджеты, цели, регулярные
платежи, настройки.

Восстановление заменяет текущие данные содержимым файла — целиком, в одной
транзакции. Если файл битый или из несовместимой версии, приложение откатит
изменения и скажет об этом; половины данных не останется.

{% hint style="warning" %}
Восстановление — это замена, а не слияние. Перед импортом сделайте экспорт
текущего состояния, если хотите его сохранить.
{% endhint %}

## Перенос на другой компьютер

1. Экспортировать бэкап на старом.
2. Установить PFN на новом.
3. **Настройки → Бэкап → Восстановить из файла.**

## Что никогда не уходит наружу

Приложение не отправляет данные на серверы. Единственный внешний запрос —
цены криптовалют с CoinGecko, и только если вы сами открыли вкладку и задали
ключ. Всё остальное работает офлайн.
