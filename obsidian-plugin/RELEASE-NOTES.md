# PFN Obsidian Plugin 0.2.0-beta.1

Первая бета плагина. Основные экраны работают, данные пишутся в обычный
markdown; формат заметок и API ещё могут меняться до стабильной версии.

## Что умеет

- **Пять вкладок**: Обзор, Операции, Бюджеты, Цели, Активы.
- **Обзор**: доход, расход, баланс, норма сбережений за месяц, расходы по
  категориям с долями, капитал (деньги + активы), последние операции.
- **Операции**: список за месяц, добавление расхода/дохода/перевода, правка и
  удаление по клику на строку.
- **Бюджеты**: лимиты по категориям, потрачено/осталось, перерасход красным.
- **Цели**: прогресс и накопленная сумма по взносам.
- **Активы**: капитал, разбивка по классам, список с риском и датой оценки.
- **Dataview из коробки**: все записи — пункты списка с inline-полями
  `[ключ:: значение]`, запросы читают их напрямую, без экспорта.
- **Работает на телефоне**: только API Obsidian, ни одного Node-модуля.

## Установка

Распаковать `pfn-finance-0.2.0-beta.1.zip` в
`<vault>/.obsidian/plugins/pfn-finance/` (три файла: `main.js`,
`manifest.json`, `styles.css`), перезапустить Obsidian и включить плагин в
**Настройки → Сторонние плагины**. Либо скриптом:

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -Vault "D:\Notes"
```

Требуется Obsidian 1.5.0+.

## Ограничения беты

- Бюджеты, цели и активы пока редактируются в markdown — форм добавления нет.
- Нет графиков и импорта CSV.
- Формат заметок может измениться до 1.0: делайте бэкап vault перед
  обновлением.
