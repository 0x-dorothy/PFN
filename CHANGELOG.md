# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## [1.2.0] — 2026-11-08

Первый публичный релиз форка **PFN (Private Finance Tracker)**, основанного на
Aurum 1.1.8 (© ZProger, PolyForm Noncommercial 1.0.0).

### Добавлено

- **Установка как у обычной программы.** `PFN-Setup.exe` для Windows (ярлык в
  «Пуск» и на рабочем столе, удаление через «Программы и компоненты»),
  `PFN-<версия>-win64.zip` для запуска без установки. Внутри — Python, FastAPI и
  собранный интерфейс: пользователю не нужны ни Python, ни Node, ни Docker.
- **Своё окно приложения** без адресной строки: `Edge/Chrome --app` по умолчанию,
  нативный `pywebview` как опция (`--window webview`).
- **Акцентные цвета оформления** — шесть пресетов (синий, фиолетовый, зелёный,
  янтарный, розовый, графит). Применяются к кнопкам, активному пункту меню,
  переключателям, фокусу полей и ссылкам; палитра графиков не меняется.
- **Лаунчер** `launcher.py` и скрипты `start.bat` / `start.sh` / `start.command`:
  проверка зависимостей, запуск, окно, PID-файл, защита от второго экземпляра,
  `--stop` для остановки.
- Сборочная обвязка: `pfn.spec` (PyInstaller), `installer/pfn.iss` (Inno Setup),
  `tools/build_windows.ps1`, `tools/make_icon.py`, CI-workflow для Windows и macOS.

### Изменено

- **Тесты бэкенда переведены на SQLite** — тот же движок, что и в поставляемой
  сборке: 142 теста, эфемерная база в памяти на каждый тест.

- **Postgres заменён на SQLite** по умолчанию: база — один файл в каталоге
  пользователя, схема создаётся из моделей и версионируется таблицей `app_meta`.
  Postgres остался опцией (`PFN_DB_BACKEND=postgres`).
- **nginx убран**: FastAPI сам отдаёт собранный SPA вместе с fallback на
  `index.html` для клиентских маршрутов. Один процесс, один порт.
- **Ребрендинг**: название, логотип, иконка, ключи `localStorage` и формат бэкапа
  вынесены в конфигурацию (`frontend/src/lib/branding.ts`,
  `backend/app/core/config.py`).
- Переменные окружения `AURUM_*` → `PFN_*`.
- Бэкап-файл теперь помечается `pfn_backup_version`.

### Исправлено

- **Восстановление бэкапа на SQLite**: вызов `pg_get_serial_sequence` выполнялся
  безусловно и падал на не-Postgres диалекте.
- **Отметки времени на SQLite читались без часового пояса.** После первого
  обновления цен вкладка «Криптовалюта» падала с `TypeError: can't subtract
  offset-naive and offset-aware datetimes` — SQLite не хранит зону, в отличие
  от Postgres. Добавлен тип `UTCDateTime`, который нормализует значения в UTC
  на входе и возвращает их с зоной на выходе.
- Тексты предупреждения об отсутствии пароля больше не ссылаются на настройки
  nginx, которых в этой сборке нет.

### Удалено

- Авторские материалы, не относящиеся к приложению: маркетинговый README,
  `CLAUDE.md`, `CONTRIBUTING.md`, конфигурация CI апстрима, Playwright-тесты,
  скриншоты, `Caddyfile` и TLS-обвязка, Dockerfile'ы и `docker-compose`.
